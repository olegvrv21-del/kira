## Trigger

Use when Oleg says "доброе утро", "что за ночь", "morning digest", "что я пропустил". Also fires from a systemd timer at 08:00 (when proactive cycle is enabled — currently not yet).

## Что собрать

### Источники (читай в этом порядке)

1. `git log --since='12 hours ago' --oneline` в `/home/exedev/webchat` — что коммитилось за ночь
2. `gh pr list --state=all --search 'updated:>=$(date -d "12 hours ago" --iso-8601)' -R olegvrv21-del/kira` — PR-активность
3. `prod_observe what=journalctl lines=200 pattern=ERROR` — ошибки за ночь
4. `self_status` — состояние системы сейчас
5. `~/notebook/TODO.md` — что было запланировано

### Что включить в дайджест

Дайджест должен быть **очень коротким** — Олег читает с телефона за минуту.

Структура:

```
☀️ Доброе утро.

За ночь:
- [главное событие 1, одна строка]
- [главное событие 2, если есть]

Состояние:
- [статус Киры одной строкой: жива/заморожена, тесты, последний deploy]

На сегодня предлагаю:
- [1-2 пункта из TODO, наиболее зрелые]

[Если есть тревожный сигнал — отдельной строкой:]
⚠️ [что не так]
```

### Длина

Максимум **5-7 строк всего**. Если хочется написать больше — не пиши, обрежь. Длинный дайджест = Олег его не прочитает.

### Когда дайджест пустой

Если за ночь ничего не произошло (нет коммитов, нет ошибок, нет PR-активности):

```
☀️ Доброе утро.

За ночь — тихо. Кира жива, тестов 890, последний deploy вчера в 18:30.
Предлагаю сегодня: [пункт из TODO].
```

## Anti-patterns

- ❌ Длинный дайджест (>10 строк)
- ❌ Технические детали (commit SHAs полностью, error stack traces) — только эффект
- ❌ Перечислять все PR подряд — только самые важные (1-2 максимум)
- ❌ Включать что-то требующее действия Олега без явного "⚠️"
